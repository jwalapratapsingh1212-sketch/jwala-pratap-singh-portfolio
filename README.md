# Jwala Pratap Singh — AI & Data Science Portfolio

A responsive React + Vite portfolio focused on Data Science, AI/ML, Generative AI, NLP and AI Agents.

## Current status
- Student portfolio; no fabricated work experience
- Projects are intentionally empty until real projects are added
- Testimonials are intentionally empty
- LinkedIn and email are connected
- Content is driven from `src/data/portfolio.json`

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```
